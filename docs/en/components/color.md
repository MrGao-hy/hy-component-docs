# Color Component

> Inside each component, a unified color scheme is used to bring a consistent and distinctive visual style to your product.

::: danger Warning

Huayue uses the scss preprocessor for better CSS authoring. Before using hy-app, please make sure your HBuilder X has the scss preprocessor installed. In most cases, you probably already have it installed. If not, go to HBuilder X -> Tools -> Plugin Installation, find "scss/sass compilation" and install it. If it does not take effect after installation, please restart HBuilder X.

:::
